# Interactive Diplopia Simulator

A browser-based teaching tool for cranial nerve palsies. Select a palsy type, adjust severity, and toggle a cover test to see how the resulting diplopia presents in each field of gaze.

I built this during my Ophthalmology rotation at Aga Khan University to teach diplopia to batchmates and interns. Static diagrams make it hard to grasp how gaze direction changes the separation of images, so I wanted something you could move and see respond. It runs entirely in the browser with no backend, so it works offline during a live session.

## Features

- **Cranial nerve palsy types** — CN III, CN IV, and CN VI presentations
- **Severity control** — adjust the degree of deviation and watch image separation change
- **Cover test toggle** — demonstrate the classic examination finding for each palsy
- **Offline** — no install, no network, no dependencies

## Running it

Download or clone the repository and open `index.html` in any modern browser.

## Built with

HTML, CSS, JavaScript

## Notes

This is a teaching aid, not a diagnostic tool. Simplifications were made deliberately to keep the underlying mechanism visible.
